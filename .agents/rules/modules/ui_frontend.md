# 🎨 Module : Frontend & Interfaces Utilisateur

> Règle Anti-Bloat : Ce module ne doit JAMAIS dépasser **80 lignes**.

- [R-UI-01] Adopter une approche strictement Mobile-First : écrire les classes de base pour mobile, puis élargir avec les breakpoints d'écran.
- [R-UI-02] Gérer systématiquement les 4 états d'affichage : chargement (skeleton), erreur (feedback), vide (empty state), et données.
- [R-UI-03] Garantir des cibles tactiles minimales de 44x44px pour tous les éléments interactifs.
- [R-UI-04] Utiliser les bibliothèques de composants accessibles (ex: Radix UI / shadcn) plutôt que de réinventer des modales ou menus manuellement.
